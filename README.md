# Who Said It? — The Office NLP Classifier

A multi-model NLP classifier that predicts which character from *The Office* said a given line of dialogue.

The repository contains the **backend only**. UI is handled separately by another team member.

## Project Structure

```
office-nlp-classifier/
├── backend.py          # Full pipeline + inference API (no UI dependencies)
├── requirements.txt    # Backend-only Python dependencies
└── models/             # Saved model artifacts (generated by running backend.py)
    ├── tfidf_vectorizer.joblib
    ├── label_encoder.joblib
    ├── pca_50.joblib
    ├── kmeans_model.joblib
    ├── logistic_regression.joblib
    └── xgboost_model.joblib
```

## Setup

```bash
cd ~/office-nlp-classifier
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

> **Apple Silicon note:** If `xgboost` fails to install, run `pip install xgboost --no-binary xgboost`

## Train & Save Models

Run the pipeline once to generate all artifacts in `models/`:

```bash
python backend.py
```

This will:
- Download the dataset from HuggingFace (~50K lines of Office dialogue)
- Preprocess text with NLTK (lemmatization + stop word removal)
- Fit TF-IDF, K-Means, Logistic Regression, and XGBoost
- Save 6 model artifacts to `models/`
- Save diagnostic plots (EDA, elbow, confusion matrices, ROC curves, learning curve) to the project root

## Inference API (for UI integration)

```python
from backend import load_artifacts, predict

arts   = load_artifacts()          # loads all models from models/
result = predict("Bears. Beets. Battlestar Galactica.", arts)
```

`predict()` returns a dict:

```python
{
    "lr_prediction":  "Dwight",          # top character — Logistic Regression
    "xgb_prediction": "Dwight",          # top character — XGBoost
    "lr_probs":  {"Dwight": 0.61, ...},  # per-character probabilities (LR)
    "xgb_probs": {"Dwight": 0.58, ...},  # per-character probabilities (XGBoost)
    "vibe":       "Dwight Energy",        # K-Means cluster label
    "cluster_id": 3,
    "clean_text": "bear beet battlestar galactica",  # preprocessed input
}
```

If the input is empty after preprocessing (all stop words / punctuation), the dict includes an `"error"` key and all prediction fields are `None`.

## Pipeline Overview

| Section | What it does |
|---|---|
| **EDA** | Class imbalance analysis, NLTK lemmatization + stop word removal, TF-IDF vectorization (5K features, unigrams + bigrams) |
| **Clustering** | PCA to 50 components, K-Means (k=5), elbow + silhouette evaluation, "vibe" label assignment |
| **Supervised** | Logistic Regression baseline, XGBoost tuned with GridSearchCV (F1-macro), learning curves |
| **Evaluation** | Classification report, confusion matrix, multi-class ROC-AUC, model comparison table |

## Dataset

Source: [`jxm/the_office_lines`](https://huggingface.co/datasets/jxm/the_office_lines) on HuggingFace

Top 7 characters modeled: Michael, Dwight, Jim, Pam, Andy, Angela, Kevin
